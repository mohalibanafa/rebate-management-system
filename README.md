# نظام إدارة خصم تعجيل الدفع المجمع (Rebate & Cash Discount Management System)

تطبيق مكتبي متكامل لنظام **Windows** مبني باستخدام **Electron + Vite + React + Tailwind CSS + SQLite (`better-sqlite3`)**.

---

## 🎯 المميزات الرئيسية (Core Features)

1. **الاحتساب اللحظي المباشر (Deterministic Re-computation / Event Replay)**:
   * حفظ الحركات كسجل عمليات خام (Ledger) وإعادة تشغيل خط السداد اللحظي عند كل عرض للكشف لمنع أي أخطاء تراكمية.
2. **توزيع السيولة بأسلوب FIFO**:
   * تغطية أقدم الفواتير المستحقة زمنياً واحتساب الخصم النسبي العادل على الجزء المسدد ضمن مهلة السماح.
3. **الربط المباشر للمرتجعات والتوالف**:
   * تخفيض صافي الفاتورة الأصلية وسيلان أي فائض نقدي سابق لتسوية الفواتير اللاحقة تلقائياً.
4. **معالجة الفائض النقدي (Overpayments)**:
   * حفظ الرصيد الدائن وتسوية الفواتير المستقبلية فور إنشائها مع احتساب خصمها.
5. **الاستثناءات الإدارية والتصحيحات**:
   * إمكانية اعتماد الخصم للفواتير المتأخرة استثنائياً مع تدوين التبرير، ووسم الحركات المعدلة بـ `[ مصححة ]`.
6. **طابور البريد البطيء الآمن (Throttled Email Queue)**:
   * إرسال الإشعارات عبر SMTP بمعدل منضبط لتجنب حظر البريد، مع تحديث أو إلغاء الرسائل عند تعديل الحركة قبل إرسالها.
7. **إغلاق السنة المالية والأرشفة السنوية**:
   * تجميد قاعدة البيانات ونقلها لمجلد الأرشيف، وتوفير عارض سنوي بوضع **للقراءة فقط (Read-Only)**.
8. **تصدير وطباعة كشوفات الحساب بصيغة PDF**.

---

## 🛠️ المكدس التقني (Tech Stack)

* **البيئة المكتبيّة**: Electron 40
* **الواجهة الأمامية**: React 19 + Tailwind CSS 4 + Lucide Icons (عبر Vite)
* **قاعدة البيانات المحلية**: SQLite3 عبر `better-sqlite3` (WAL Mode)
* **محرك البريد**: Nodemailer مع طابور جدولة داخلي
* **التحزيم والتثبيت**: Electron Builder (NSIS Windows Installer `.exe`)

## 🚀 التشغيل والتطوير المحلي

```powershell
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير السريعة (Vite + Electron)
npm run electron:dev

# تشغيل النسخة المجمعة
npm run electron:start

# تشغيل اختبارات الوحدات البرمجية
npm test

# بناء حزمة التثبيت لنظام ويندوز (.exe)
npm run package
```
